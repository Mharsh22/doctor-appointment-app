# Doctor's Hub 🏥

A doctor appointment booking app built with React and TypeScript.

## Live Demo
[doctorhub-app.vercel.app](https://doctorhub-app.vercel.app)

## Features
- Browse and search doctors by name or specialty
- View detailed doctor profiles with ratings, fees, and availability
- Book appointments with available doctors
- View and cancel booked appointments

## Tech Stack
- React 18
- TypeScript
- Tailwind CSS
- React Router v6
- localStorage for data persistence

## Getting Started

- git clone https://github.com/Mharsh22/doctor-appointment-app.git
- cd doctor-appointment-app
- npm install
- npm run dev
